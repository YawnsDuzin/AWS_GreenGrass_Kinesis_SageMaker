## 비용 최적화 팁

### 1. 예약 용량 사용

| 옵션 | 할인율 | 적합 대상 |
|------|--------|----------|
| Savings Plans (1년) | 최대 30% | 예측 가능한 워크로드 |
| Savings Plans (3년) | 최대 50% | 장기 운영 |
| Reserved Instances | 최대 72% | 특정 인스턴스 고정 |

### 2. 올바른 인스턴스 선택

```
# GPU 추론: g4dn vs inf1
ml.g4dn.xlarge: $0.736/h (T4 GPU, 범용)
ml.inf1.xlarge: $0.297/h (Inferentia, 특화) - 60% 저렴

# 비용 최적화 선택
ml.inf1 사용 시 월간 절감: $316 (530 → 214)
```
