## 서비스별 구성

### GreenGrass 컴포넌트 구성

```yaml
# deployment.yaml
components:
  # 핵심 컴포넌트
  aws.greengrass.Nucleus:
    version: "2.12.0"

  # 스트림 관리
  aws.greengrass.StreamManager:
    version: "2.1.0"
    configuration:
      STREAM_MANAGER_STORE_ROOT_DIR: "/data/stream_manager"

  # 안전 감지 컴포넌트
  com.safety.DetectionComponent:
    version: "1.0.0"
    configuration:
      modelPath: "/greengrass/v2/models/yolov8_safety.onnx"
      confidenceThreshold: 0.8
      cameraSources:
        - "rtsp://192.168.1.101:554/stream"
        - "rtsp://192.168.1.102:554/stream"

  # 환경 모니터링 컴포넌트
  com.safety.EnvironmentMonitor:
    version: "1.0.0"
    configuration:
      sensorPollingInterval: 5000
      alertThresholds:
        temperature: 35
        co_ppm: 50
        humidity: 80

  # 위험구역 감지 컴포넌트
  com.safety.DangerZoneMonitor:
    version: "1.0.0"
    configuration:
      zones:
        - name: "crane_area"
          polygon: [[100,100], [300,100], [300,400], [100,400]]
          severity: "HIGH"
```
