## 계층별 상세 설명

### 1. Field Layer (현장 계층)

현장에서 데이터를 수집하고 1차 처리를 수행하는 계층입니다.

#### 디바이스 구성

| 디바이스 | 용도 | 데이터 형식 | 주요 사양 |
|----------|------|-------------|-----------|
| IP Camera (CCTV) | 영상 감시 | H.264/H.265 Video | 4K, 30fps, PoE |
| Thermal Camera | 열화상 감지 | FLIR Format | 384x288, 온도 정확도 ±2°C |
| Gas Sensor | 유해가스 감지 | JSON | CO, H2S, O2, LEL |
| Wearable Device | 작업자 상태 모니터링 | JSON | 심박수, 위치, 낙상 감지 |
| Drone Camera | 고소작업 감시 | H.264 Video | 4K, GPS 탑재 |
| RFID Reader | 출입 관리 | RFID Tag ID | UHF 860-960MHz |

#### AWS IoT GreenGrass Core Device

```yaml
# GreenGrass Core 구성
GreenGrass Core Device:
  Hardware:
    - NVIDIA Jetson Xavier NX (권장)
    - Intel NUC with GPU
    - AWS Panorama Appliance

  Software Components:
    - ML Inference Component: 실시간 객체 감지
    - Data Filter Component: 중요 이벤트만 필터링
    - Local Store Component: 오프라인 시 데이터 임시 저장
    - Stream Manager Component: Kinesis로 데이터 전송

  Capabilities:
    - 로컬 ML 추론 (저지연)
    - 오프라인 동작 지원
    - OTA 업데이트
    - 보안 통신 (TLS 1.2+)
```

### 3. Ingestion Layer (수집 계층)

데이터를 수집하고 스트림으로 전달하는 계층입니다.

#### AWS IoT Core

```python
# IoT Core 규칙 예시 (SQL)
SELECT
    topic(2) as device_id,
    timestamp() as event_time,
    temperature,
    gas_level,
    CASE
        WHEN temperature > 50 THEN 'HIGH_TEMP_ALERT'
        WHEN gas_level > 100 THEN 'GAS_ALERT'
        ELSE 'NORMAL'
    END as alert_type
FROM
    'construction-site/+/sensors'
WHERE
    temperature > 40 OR gas_level > 50
```

### 4. Processing Layer (처리 계층)

실시간 데이터 처리 및 분석을 수행하는 계층입니다.

#### Kinesis Data Analytics

```sql
-- 실시간 위험 감지 쿼리
CREATE OR REPLACE STREAM "ALERT_STREAM" (
    device_id VARCHAR(50),
    alert_type VARCHAR(50),
    severity VARCHAR(20),
    event_time TIMESTAMP,
    details VARCHAR(1000)
);

CREATE OR REPLACE PUMP "ALERT_PUMP" AS
INSERT INTO "ALERT_STREAM"
SELECT STREAM
    device_id,
    alert_type,
    CASE
        WHEN confidence > 0.9 THEN 'CRITICAL'
        WHEN confidence > 0.7 THEN 'WARNING'
        ELSE 'INFO'
    END as severity,
    ROWTIME as event_time,
    details
FROM "SOURCE_STREAM"
WHERE alert_type IS NOT NULL;
```

#### Lambda 함수 역할

| 함수 | 트리거 | 역할 |
|------|--------|------|
| AlertingLambda | Kinesis | 위험 감지 시 SNS로 알림 발송 |
| AnalysisLambda | Kinesis | 데이터 분석 및 집계 |
| ETLLambda | Kinesis Firehose | 데이터 변환 및 S3 저장 |

### 6. Storage Layer (저장 계층)

다양한 유형의 데이터를 저장하는 계층입니다.

| 저장소 | 데이터 유형 | 용도 | 보존 기간 |
|--------|-------------|------|-----------|
| Amazon S3 | Raw Video, Images, Models | 원본 데이터 아카이빙, ML 모델 저장 | 1년+ |
| DynamoDB | Event Metadata | 이벤트 기록, 빠른 조회 | 90일 |
| Timestream | Sensor Time Series | 시계열 분석 | 30일 |
| Glacier | Compliance Data | 법적 보존 | 7년 |
