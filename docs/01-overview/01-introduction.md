# 1.1 프로젝트 소개 및 목표

## 개요

본 프로젝트는 AWS의 핵심 IoT 및 ML 서비스인 **AWS IoT GreenGrass**, **Amazon Kinesis**, **Amazon SageMaker**를 통합하여 공사현장에서 발생할 수 있는 안전 사고를 예방하고 실시간으로 위험 상황을 감지하는 시스템을 구축하는 것을 목표로 합니다.

---

## 프로젝트 배경

### 건설 현장 안전의 중요성

건설업은 전 세계적으로 가장 위험한 산업 중 하나입니다:

| 통계 항목 | 수치 | 출처 |
|-----------|------|------|
| 한국 건설업 사망자 수 (2023) | 약 400명 이상 | 고용노동부 |
| 건설업 재해율 | 전체 산업의 약 25% | 산업안전보건공단 |
| 주요 사고 유형 | 추락(50%), 낙하물(15%), 감전(10%) | KOSHA |
| 경제적 손실 | 연간 수조원 | 건설안전학회 |

## 프로젝트 목표

### 주요 목표

1. **실시간 위험 감지 시스템 구축**
   - 카메라 및 센서 데이터 실시간 분석
   - 위험 상황 즉시 알림
   - 자동화된 안전 모니터링

2. **AI 기반 사고 예방**
   - 머신러닝을 활용한 위험 패턴 분석
   - 사고 발생 예측 모델 개발
   - 선제적 안전 조치 권고

3. **엣지 컴퓨팅 활용**
   - 현장에서의 저지연 처리
   - 네트워크 의존성 최소화
   - 오프라인 환경에서도 동작

4. **확장 가능한 아키텍처**
   - 다중 현장 동시 관리
   - 손쉬운 기능 확장
   - 비용 효율적 운영

### 세부 목표

| 카테고리 | 목표 | KPI |
|----------|------|-----|
| 감지 속도 | 위험 상황 감지 및 알림 | < 3초 |
| 정확도 | 안전장비 미착용 감지 정확도 | > 95% |
| 가용성 | 시스템 가동률 | 99.9% |
| 비용 | 기존 대비 운영비 절감 | > 30% |
| 커버리지 | 현장 내 감시 범위 | > 90% |

### 서비스별 역할

| 서비스 | 역할 | 핵심 기능 |
|--------|------|-----------|
| **AWS IoT GreenGrass** | 엣지 컴퓨팅 | 현장 디바이스 관리, 로컬 ML 추론, 데이터 전처리 |
| **Amazon Kinesis** | 실시간 스트리밍 | 대용량 데이터 수집, 실시간 처리, 데이터 저장소 연동 |
| **Amazon SageMaker** | ML/AI | 모델 학습/배포, 실시간 추론, MLOps 자동화 |

## 적용 시나리오

### 시나리오 1: 안전장비 미착용 감지

```
[카메라] → [GreenGrass 엣지 추론] → [위반 감지] → [즉시 경보]
                                         │
                                         ▼
                               [Kinesis로 이벤트 전송]
                                         │
                                         ▼
                               [SageMaker 추가 분석]
                                         │
                                         ▼
                               [대시보드 업데이트 + 기록]
```

### 시나리오 2: 위험 구역 침입 감지

```
[작업자 위치 추적] → [위험 구역 정의] → [침입 감지] → [경고 발송]
                                              │
                                              ▼
                                    [작업 중지 권고]
```

### 시나리오 3: 환경 위험 모니터링

```
[센서 데이터 수집] → [이상 패턴 감지] → [위험 수준 평가] → [대피 알림]
  (온도, 가스, 진동)
```

## 기대 효과

### 정량적 효과

| 항목 | 현재 | 목표 | 개선율 |
|------|------|------|--------|
| 사고 발생률 | 100% (기준) | 30% | 70% 감소 |
| 위험 감지 시간 | 수분~수시간 | 3초 이내 | 99% 개선 |
| 안전 점검 인력 | 10명/현장 | 3명/현장 | 70% 절감 |
| 안전 교육 효과 | 측정 어려움 | 데이터 기반 피드백 | 정량화 가능 |

### 정성적 효과

- **작업자 안전 의식 향상**: 실시간 모니터링에 따른 자발적 안전수칙 준수
- **기업 이미지 개선**: 첨단 안전관리 시스템 도입으로 신뢰도 상승
- **법적 리스크 감소**: 안전관리 의무 이행 증빙 자료 자동 생성
- **보험료 절감**: 사고율 감소에 따른 산재보험료 인하 가능
