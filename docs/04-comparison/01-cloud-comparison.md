## 1. 엣지 컴퓨팅 서비스 비교

| 특성 | AWS IoT GreenGrass | Azure IoT Edge | GCP Cloud IoT Edge |

| **아키텍처** | 컴포넌트 기반 | 모듈 기반 | 컨테이너 기반 |

## 2. 스트리밍 서비스 비교

### 서비스 개요

| 특성 | Amazon Kinesis | Azure Event Hubs | GCP Pub/Sub + Dataflow |
|------|---------------|------------------|----------------------|
| **데이터 수집** | Kinesis Data Streams | Event Hubs | Cloud Pub/Sub |
| **실시간 분석** | Kinesis Data Analytics | Stream Analytics | Dataflow (Apache Beam) |
| **데이터 전송** | Kinesis Firehose | Event Hubs Capture | Dataflow |
| **비디오 스트림** | Kinesis Video Streams | Video Analyzer | Video Intelligence |

### 요금 비교

| 항목 | Amazon Kinesis | Azure Event Hubs | GCP Pub/Sub |
|------|---------------|------------------|-------------|
